# Desktop Pet（macOS 桌面宠物）

菜单栏常驻的桌面宠物：把绿幕猫猫视频抠成透明片段，在屏幕上无边框浮动播放。支持多片段库、播放队列、三种播放模式、首尾帧自动衔接，以及随机隐现与鼠标附近提醒。

应用以 `NSUIElement` 方式运行（无 Dock 图标），通过菜单栏猫图标控制。

## 能做什么

### 桌面宠物窗口

- 透明无边框窗口，默认出现在主屏右下角，可拖到任意位置（拖动会取消进行中的隐现）
- **置顶**：浮在普通窗口之上（默认开启）
- **点击穿透**：鼠标事件穿透宠物，不挡操作
- **大小**：缩放约 0.4×–2.2×
- 跟随全部 Spaces / 全屏辅助空间

### 片段库

窗口标题：**桌面宠物 · 片段库**。

| 操作 | 说明 |
|------|------|
| **添加视频…** | 多选 MP4 / MOV，复制到应用目录后抠像导入 |
| **全选 / 取消全选** | 配合 ⌘ / Shift 多选 |
| **上移 / 下移** | 调整片段在列表中的顺序 |
| **按所选播放** | 将选中片段设为播放队列并开始播放 |
| **清除队列** | 清空队列，恢复「播放全部」 |
| **删除** | 删除选中片段及其透明帧 |
| **重命名…** | 详情区改名（如「趴着」「伸懒腰」） |
| **重算衔接** | 按当前相似度阈值重写自动衔接边 |

列表每行展示：首/尾帧缩略图、标题、时长与帧数、导入时间、**播放次数（N 次）**；队列中显示 **队列 #k**，正在播放显示 ▶。

### 播放模式

设置栏 **播放模式**：

| 模式 | 行为 |
|------|------|
| **顺序播放** | 按列表（或队列）顺序循环 |
| **随机播放** | 随机下一段，尽量避开最近刚播过的片段 |
| **衔接播放** | 优先走「可衔接下一段」；若无配置则按首尾帧相似度选最佳下一段 |

有播放队列时，只在队列内循环；无队列时播放全部片段。

### 抠绿幕导入

1. 选择视频后弹出 **抠绿幕预览**（前段 / 中段 / 后段采样）
2. 可调 **抠图强度**、**边缘羽化**、**去绿边**，不满意可恢复默认
3. **接受并导入** 后导出带 alpha 的 PNG 序列

技术说明：ffmpeg 解码缩放；Swift 侧对「与画面边缘连通的绿色」做抠像（主体内部绿色保留），边缘去溢色，并按主体裁切归一化。需本机安装 ffmpeg。

### 自动衔接

- 比较 A 的**尾帧**与 B 的**首帧**指纹，相似度 ≥ 阈值则推荐为衔接边
- 详情区 **可衔接的下一段** 可手动勾选 / 取消；勾选后在「衔接播放」模式下生效
- 导入完成或点击 **重算衔接** 可批量更新

### 随机隐现与提醒

| 设置 | 说明 |
|------|------|
| **随机隐现** | 片段播完后按概率消失 → 换位置 → 再出现（在末帧停一下，避免播到一半被打断） |
| **片段末概率** | 控制每次片尾触发隐现的概率 |
| **鼠标附近提醒** | 约四分之一的隐现落到鼠标附近，其余落在屏幕角落（支持多显示器） |
| **编辑提醒文案…** | 每行一条；出现在鼠标附近时弹出气泡（默认如「喝点水吧」「站起来走走」） |

### 菜单栏

菜单栏图标（猫）：

- **打开片段库**（⌘L）
- **显示/隐藏宠物**（⌘P）
- **退出**（⌘Q）

### 开机启动

底部勾选 **开机启动**（需通过 `DesktopPet.app` 启动）。若系统要求批准：到 **系统设置 → 通用 → 登录项** 中允许 DesktopPet。

### 播放统计

每个片段开始播放时累加次数，列表右侧显示 **N 次**，便于核对随机/队列是否真正覆盖到全部片段。

## 依赖

- macOS 13+
- [ffmpeg](https://ffmpeg.org/)（导入抠像）
- Xcode / Swift 工具链（构建）

```bash
brew install ffmpeg
```

## 构建与运行

```bash
cd /path/to/desktop-pet
chmod +x build_app.sh
./build_app.sh
open DesktopPet.app
```

首次启动若库为空，会尝试导入目录下的示例绿幕视频并抠像。

## 数据位置

```
~/Library/Application Support/DesktopPet/
  library.json          # 片段元数据、播放模式、设置、播放次数
  clips/<id>/frames/    # 透明 PNG 序列（00001.png …）
```
