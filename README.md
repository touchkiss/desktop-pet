# Desktop Pet（macOS 桌面宠物）

菜单栏常驻的桌面宠物：把绿幕猫猫视频抠成透明片段，在屏幕上无边框浮动播放。支持多片段库、播放队列、三种播放模式、首尾帧自动衔接，以及带电影感特效的随机隐现传送、摸猫/甩猫互动、番茄钟与下载嗅探等陪伴功能。

应用以 `NSUIElement` 方式运行（无 Dock 图标），通过菜单栏猫图标控制。

## 能做什么

### 桌面宠物窗口

- 透明无边框窗口，默认出现在主屏右下角，可拖到任意位置（拖动会取消进行中的隐现）
- **置顶**：浮在普通窗口之上（默认开启）
- **点击穿透**：鼠标事件穿透宠物，不挡操作
- **大小**：缩放约 0.4×–2.2×
- 跟随全部 Spaces / 全屏辅助空间
- 片段尺寸不同时以**底边中心**为锚点换装：脚保持落地，不跳位
- **阻止自动锁屏与关闭屏幕**：使用 macOS 显示空闲休眠断言保持屏幕常亮，并同时阻止系统因空闲进入睡眠；不会阻止 `⌃⌘Q`、系统菜单锁屏、合盖或主动睡眠。
- 独立的屏幕保护程序、组织 MDM 或其他安全策略仍会照常生效，本功能不会尝试绕过它们。
- **空闲后放大**：可在 1/3/5/10/15/30 分钟无键鼠输入后，以 1.0×–3.0× 魔性倍率额外放大猫猫；真实输入后通常在下一次采样、约 1 秒内恢复正常大小。

### 互动

| 交互 | 行为 |
|------|------|
| **摸猫** | 点按猫咪：随机播放一段勾选了「被摸反应」的片段并弹气泡；没有标记片段时也会回一句「喵？」 |
| **甩猫** | 拖住快速一甩把猫抛出去：带重力、屏幕边缘反弹与落地滑停 |
| **召唤到光标** | 全局热键 **⌃⌥C**（或菜单栏点选）：猫用一次完整传送落到鼠标附近（Carbon 热键，无需辅助功能权限） |
| **鼠标目标互动** | 自主随机传送到鼠标附近时，用一段透明目标动画临时替换指针，并播放猫咪扑抓片段；结束或中断后自动恢复指针和普通播放 |

### 片段库

窗口标题：**桌面宠物 · 片段库**。

| 操作 | 说明 |
|------|------|
| **添加视频…** | 多选 MP4 / MOV，复制到应用目录后抠像导入 |
| **全选 / 取消全选** | 配合 ⌘ / Shift 多选 |
| **上移 / 下移** | 调整片段在列表中的顺序 |
| **按所选播放** | 将选中片段设为播放队列并开始播放 |
| **清除队列** | 清空队列，恢复「播放全部」 |
| **删除** | 删除选中片段及其透明帧 |
| **导出 GIF…** | 把选中片段导出为循环 **GIF**（兼容表情包）或 **APNG**（无损透明） |
| **重命名…** | 详情区改名（如「趴着」「伸懒腰」） |
| **重算衔接** | 按当前相似度阈值重写自动衔接边 |

列表每行展示：首/尾帧缩略图、标题、时长与帧数、导入时间、**播放次数（N 次）**；队列中显示 **队列 #k**，正在播放显示 ▶。

详情区自带**整段预览播放器**：240×240 棋盘格底纹（透明通道一目了然），自动循环，支持播放/暂停、拖动进度条与帧计数；下方保留首/尾帧缩略图供衔接参考。此外可重命名、勾选**被摸反应片段（点按猫咪时播放）**、编辑**可衔接的下一段**。

猫猫详情还提供**尺寸标定**：默认以列表第一只猫的抠像首帧作为 30% 不透明度的参照，也可以指定其他猫。先调好参照片段的倍率，再点击“更新参照”固定标尺；切换其他片段后，用尺寸滑块或倍率输入框（0.25–3.00×）对照调整，修改即时保存。两只猫共用画布比例，底部基线和中心线辅助对齐；可拖动实色猫、选择当前帧，或同时缩放画布。参照可隐藏、调整不透明度，选择会在重启后保留；拖动和画布缩放只影响比较视图。不同姿势的视觉体型需要人工判断，不能仅按外接宽高衡量。

如果视频基本来自同一张首帧，点击**首帧批量标定…**即可按参照自动计算其他猫猫的尺寸。算法比较抠像首帧的主体轮廓和实际显示面积，忽略透明留白及零散噪点；预览会列出原倍率、建议倍率及跳过原因，确认后一次保存。参照本身与互动目标素材不变，首帧差异明显、无效或建议倍率越界的片段会跳过。**撤销批量标定**可恢复最近一次批量修改（应用本次运行期间有效）；相关片段后来被修改或删除时会拒绝覆盖。全局大小不影响计算结果，也不会改写 PNG 或桌面位置。

鼠标互动素材仍按普通视频方式导入并抠成透明 PNG 序列，然后在详情中二选一标记为 **鼠标互动目标素材**（苍蝇、小虫、逗猫棒、猫玩具等）或 **鼠标互动猫片段**。每个目标素材可独立设置 16–128 pt 的最长边尺寸（默认 48 pt），棋盘格预览会即时按设置缩放；调整尺寸不会重新导出帧。两类专用素材不进入普通播放队列或自动衔接。

### 播放模式

设置栏 **播放模式**：

| 模式 | 行为 |
|------|------|
| **顺序播放** | 按列表（或队列）顺序循环 |
| **随机播放** | 随机下一段，尽量避开最近刚播过的片段 |
| **衔接播放** | 优先走「可衔接下一段」；若无配置则按首尾帧相似度选最佳下一段 |

有播放队列时，只在队列内循环；无队列时播放全部片段。

### 抠绿幕导入

1. 选择视频后弹出 **抠绿幕预览**（前段 / 中段 / 后段采样）
2. 可调 **抠图强度**、**边缘羽化**、**去绿边**，不满意可恢复默认
3. **接受并导入** 后导出带 alpha 的 PNG 序列

技术说明：ffmpeg 解码缩放；Swift 侧对「与画面边缘连通的绿色」做抠像（主体内部绿色保留），边缘去溢色，并按主体裁切归一化。需本机安装 ffmpeg。

### 自动衔接

- 比较 A 的**尾帧**与 B 的**首帧**指纹，相似度 ≥ 阈值则推荐为衔接边
- 详情区 **可衔接的下一段** 可手动勾选 / 取消；勾选后在「衔接播放」模式下生效
- 导入完成或点击 **重算衔接** 可批量更新

### 随机隐现与传送特效

触发与落点：

| 设置 | 说明 |
|------|------|
| **随机隐现** | 开启后每段片尾按概率触发传送；消失特效在片尾前约 0.75 秒就启动——猫还在动的时候溶解，而不是先定格再消失 |
| **片段末概率** | 控制每次片尾触发隐现的概率（左低右高） |
| **鼠标附近提醒** | 约四分之一的落点在鼠标旁并弹出提醒气泡，其余落在屏幕角落（支持多显示器） |
| **编辑提醒文案…** | 每行一条（默认如「喝点水吧」「站起来走走」） |

若两类鼠标互动素材都存在，自主随机的鼠标附近落点会随机配对一份目标和一段猫咪动作，并以目标互动代替提醒气泡。菜单召唤、全局热键、番茄钟、下载提醒和特效预览仍使用原有气泡，不会触发目标互动；任一素材缺失或帧不可用时也会安全回退到普通提醒。

隐藏期间引擎停在末帧，出现时下一段已经开播，落地即活；整个旅程方向一致——消失朝去向、桥接沿弧线飞、出现从来向滑入。特效期间引擎帧持续喂给特效层，猫在溶解 / 重组过程中也保持动作。

消失与出现的特效**每次独立随机抽取**（可任意组合），共 9 种风格：

| 风格 | 效果 |
|------|------|
| **化灰** | 噪声碎块逐像素溶解，尘埃沿溶解前沿飘散，方向跟随行程 |
| **老电视** | CRT 关机 / 开机：画面塌缩成一道炽亮扫描线 |
| **闪现** | 瞬移步：微退蓄力后朝去向冲出，带残影拖尾 |
| **像素块** | 马赛克碎裂散落；出现时碎块飞回、底行先合 |
| **拉丝** | 沿行进方向拉出动态模糊光丝 |
| **扫描线** | 亮线自上而下逐行擦除 / 打印猫身，带色散镶边 |
| **墨滴** | 消失时去色虚化、如墨入水从毛边晕开；出现时墨滴自中心洇开凝形 |
| **显影** | 老照片显影 / 褪色 |
| **像素洪流** | 一体化整段旅程：碎裂成像素、汇成一股细流沿弧线飞抵（带光痕）、到点重组 |

位移感风格（闪现 / 拉丝 / 墨滴）组合的旅程，隐藏段还会抽取一种**桥接**连接两端：**彗星光痕**（配色随风格——暖金 / 冷蓝 / 水墨）、**筋斗云**（小云驮着猫影飞过）、**妖风缠绕**（多股光互相缠绕）、**残影连跳**（白色剪影沿途逐跳闪现）。擦除类风格保持经典的静默重现；像素洪流自成旅程，不叠加桥接。

菜单栏 **预览隐现特效** 可即点即看任意风格（或随机），便于调参。

### 番茄钟

菜单栏 **番茄钟 → 开始**：专注 25 分钟 + 休息 5 分钟（单轮）。每个阶段结束时，猫会传送到光标旁用气泡提醒（「专注结束，站起来活动一下吧」/「休息够了，继续加油」）。

### 下载嗅探

监控 `~/Downloads`：有新文件下载完成时，猫传送到光标旁报告「有新文件：xxx」。忽略浏览器临时文件（.part / .crdownload 等），2 秒防抖、至少间隔 90 秒才报一次。菜单栏可开关，默认开启。

### 菜单栏

菜单栏图标（猫）：

- **打开片段库**（⌘L）
- **显示/隐藏宠物**（⌘P）
- **预览隐现特效**：9 种风格逐个点验，或 **随机风格**（⌘T）
- **召唤到光标（⌃⌥C）**
- **番茄钟**：开始 / 停止
- **下载嗅探**（勾选开关）
- **退出**（⌘Q）

### 开机启动

底部勾选 **开机启动**（需通过 `DesktopPet.app` 启动）。若系统要求批准：到 **系统设置 → 通用 → 登录项** 中允许 DesktopPet。

### 播放统计

每个片段开始播放时累加次数，列表右侧显示 **N 次**，便于核对随机/队列是否真正覆盖到全部片段。

## 依赖

- macOS 13+
- [ffmpeg](https://ffmpeg.org/)（导入抠像）
- Xcode / Swift 工具链（构建）

```bash
brew install ffmpeg
```

## 构建与运行

```bash
cd /path/to/desktop-pet
chmod +x build_app.sh
./build_app.sh
open DesktopPet.app
```

跑单元测试（DesktopPetCore 纯函数：传送时序、路径几何、落点选择等）：

```bash
swift test
```

首次启动若库为空，会尝试导入目录下的示例绿幕视频并抠像。

## 数据位置

```
~/Library/Application Support/DesktopPet/
  library.json          # 片段元数据、播放模式、设置、播放次数、行为标签、逐目标显示尺寸、衔接关系
  clips/<id>/frames/    # 透明 PNG 序列（00001.png …）
```

### 透明视频素材与旧库升级

- 启动后后台串行将旧 PNG 序列转换为 `animation.mov`（HEVC + Alpha），保留 `frames/` 中首尾 PNG；片段 ID、标签、队列、尺寸和衔接信息不变，无须重新导入。
- 旧完整序列保存在片段目录的 `png-backup/`，可用于失败恢复。转换中断后下次启动继续；菜单栏显示升级进度，失败可点击重试，错误记录在应用数据目录的 `media-migration-errors.txt`。
- 新导入仍按预览参数抠图，完成后直接生成透明 MOV 和首尾帧，不保留中间 PNG。日常播放与预览使用系统视频层；校准、导出和特效按需取帧。
- HEVC 编码使用偶数尺寸。奇数宽高素材全幅重采样至相邻偶数尺寸，显示仍使用原片段宽高比例；首尾 PNG 保留原图。`animation.validated.json` 记录已验证产物，避免每次启动重新解码整个素材库。
- 「开机启动」旁的「启动后最小化窗口」可让启动时仅显示宠物，不弹出片段库。
