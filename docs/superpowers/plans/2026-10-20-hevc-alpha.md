# HEVC Alpha 素材迁移与播放实施计划

**目标：** 现有 PNG 片段自动转换为 HEVC Alpha MOV + 首尾 PNG，以后导入同样转换，不需重新导入。

**架构：** 视频产物验证成功后原子发布；按片段 ID 保留全部业务元数据。普通播放使用 AVPlayerLayer，特殊取帧从视频读取。旧素材转换失败继续 PNG 播放。旧 PNG 在迁移成功后移入可恢复备份，避免不可逆丢失。

**技术：** macOS 13+、AVFoundation、ImageIO、现有抠图流程。

- [x] 透明视频编码：逐帧 BGRA 输入 HEVC Alpha；验证透明轨、帧数/时长、首尾可解码；临时文件原子发布；失败清理临时文件。
- [x] 自动迁移和新导入：后台串行、可重入、失败保留原帧；首尾 PNG 留存；显示进度和错误。
- [x] 视频播放：系统播放器渲染，保留片段结束/提前结束通知、暂停末帧、互动片段及随机切换。
- [x] 兼容读取：片段预览、首帧校准、传送快照、鼠标目标、GIF 导出适配 MOV 中间帧。
- [x] 验证：合成透明素材编码测试、失败重试/旧素材测试、完整 swift test、release build、真实素材批量迁移及 UI/CPU 检查。

现有未提交校准改动保留；不提交、不清理用户源视频。禁止仅转换容器而仍逐帧 PNG 主播放。

- 编码smoke：奇偶尺寸、单帧、非整数fps、透明/半透明、不对称边缘、失败清理、目标文件冲突均通过。
- 独立代码审查通过；修复时间基偏帧、循环seek时钟、奇数尺寸裁切、当前视频重载以及GIF/APNG画布不一致。
- 实际素材库156/156完成；逐片段确认MOV、version 2验证记录、首尾PNG集合、备份帧数。库JSON除播放次数外与迁移前一致。
- 转码结束后20.02秒进程CPU时间增量测得平均5.14%，期间开始播放2个片段；瞬时4.4%。非同片段受控基准，不推导固定降幅。
