# 素材分类 Tab 与猫猫片段独立缩放设计

## 目标

将片段库直接分为“猫猫”和“鼠标互动目标素材”两个 Tab，允许用户在抠像预览弹窗中为每个待导入视频选择素材类型，并允许每个猫猫片段保存独立缩放倍率。猫猫最终显示倍率为“片段倍率 × 全局倍率”。

## 范围

- 片段库左侧列表增加“猫猫”和“鼠标互动目标素材”两个 Tab。
- 抠像预览弹窗增加素材类型选择，选项为“猫猫”和“鼠标互动目标素材”，默认“猫猫”。
- 每个非目标素材片段保存 `0.25×–3.00×` 的独立猫猫倍率，默认 `1.00×`。
- 保留现有全局“大小”设置，最终猫猫倍率为片段倍率与全局倍率的乘积。
- 复用现有 `cursorPrey` 标签、目标素材独立 pt 尺寸及互动播放逻辑。
- 不拆分磁盘素材目录，不重新生成已经完成抠像的 PNG 帧。

## 素材分类

`PetClip.tags` 继续作为素材角色的兼容来源：

- 包含 `cursorPrey` 的片段显示在“鼠标互动目标素材”Tab。
- 不包含 `cursorPrey` 的片段显示在“猫猫”Tab，包括普通猫片段和带 `cursorInteraction` 标签的互动猫片段。

该规则只划分两个用户可见素材大类，不改变 `cursorInteraction` 的专用播放语义。现有详情面板仍允许调整鼠标互动角色；角色变化后，片段立即移动到对应 Tab。

## 数据模型与兼容

为 `PetClip` 增加可编码的独立猫猫倍率字段。字段采用向后兼容解码：旧 `library.json` 缺少该字段时使用 `1.00`。独立倍率的有效范围固定为 `0.25×–3.00×`；写入和读取时都执行限制，非有限值回退到 `1.00×`，防止损坏或异常数据产生不可用窗口尺寸。全局倍率继续沿用现有 `0.40×–2.20×` 范围。

鼠标互动目标继续使用 `CursorPreySettings.displaySize`，不使用猫猫片段倍率，也不受全局猫猫大小影响。

不对旧素材进行破坏性迁移；已有标签、播放次数、衔接关系和队列数据保持不变。

## 片段库交互

左侧列表头部使用双段选择控件表示两个 Tab。列表数据源由当前 Tab 对应的过滤结果提供，所有行索引必须先映射回真实 `PetClip.id`，避免对过滤后的行号直接操作完整数组。

以下操作只作用于当前 Tab 的可见素材：

- 选择、全选与取消选择；
- 删除和导出；
- 上移与下移；
- 详情展示与重命名。

播放队列、按所选播放和自动衔接只对可播放猫猫有效。目标素材 Tab 中不允许创建普通播放队列。切换 Tab 时停止旧详情预览，并清除不再可见的选择；默认选中当前 Tab 第一项（如果存在）。计数文案显示当前 Tab 数量，并保留全库总数信息。

## 导入流程

`ChromaKeyPreviewController` 在现有抠像参数下方增加“素材类型”单选控件。弹窗确认结果同时返回抠像设置与所选素材类型：

- “猫猫”：按普通猫素材提交，不增加 `cursorPrey` 标签。
- “鼠标互动目标素材”：提交后增加 `cursorPrey` 标签，并创建默认 `CursorPreySettings`。

批量导入仍逐个显示预览，因此用户可以为每个视频独立选择类型。取消预览时继续丢弃本次 staging 数据。目标素材导入成功后切换到目标 Tab 并选中它，但不调用普通猫播放；猫猫导入成功后切换到猫猫 Tab、选中并播放。

应用自动导入示例猫猫的路径继续默认按“猫猫”处理。

## 猫猫独立缩放

猫猫详情面板增加：

- 独立倍率滑块；
- 当前片段倍率数值；
- “恢复默认”按钮；
- 最终倍率说明，例如 `片段 0.80× × 全局 1.20× = 0.96×`。

滑块变更立即保存并刷新桌面猫窗口。最终尺寸计算为：

```text
最终宽度 = displayWidth × clipScale × petScale
最终高度 = displayHeight × clipScale × petScale
```

所有猫猫呈现路径使用同一计算规则，包括普通轮播、互动猫单次播放、窗口刷新及传送落点尺寸计算。鼠标互动目标覆盖窗口继续使用其独立 point 尺寸。

## 边界与错误处理

- 旧素材缺少独立倍率时按 `1.00×` 显示。
- 非有限值、过小或过大的倍率被限制到有效范围。
- 目标素材不会因为遗留的猫猫倍率字段而改变显示尺寸。
- 当前选中片段因标签变化离开当前 Tab 时，界面切换到对应 Tab 并重新选择该片段。
- 当前播放猫片段被改为目标素材时，沿用现有 library change 同步逻辑恢复到有效普通播放项。
- 导入失败或取消时不新增片段，也不改变当前 Tab。

## 测试策略

将确定性规则放入 `DesktopPetCore` 或可独立测试的数据模型辅助类型，并用 XCTest 覆盖：

- 素材分类：`cursorPrey` 进入目标 Tab，普通猫和 `cursorInteraction` 进入猫猫 Tab；
- 独立倍率默认值、上下限钳制及异常值回退；
- 最终倍率和最终显示尺寸为独立倍率与全局倍率的乘积；
- 旧 JSON 缺少独立倍率时仍可解码并得到 `1.00×`；
- 导入类型到标签/默认设置的映射；
- 过滤列表的 ID 映射，确保删除、排序和选择不会误操作完整数组中的其他片段。

完成后运行 `swift test` 和 `swift build`，并手动检查两个 Tab、逐视频导入类型选择、猫猫缩放实时刷新以及目标素材不进入普通播放。
