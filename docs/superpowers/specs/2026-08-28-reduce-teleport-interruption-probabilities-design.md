# 降低传送打扰概率设计

## 目标

将可能打断工作的两项自主传送概率统一降低 80%，即新的概率为原概率的 20%。

## 行为调整

- 勾选“鼠标附近提醒”时，自主传送选择鼠标附近落点的概率从 `25%` 降为 `5%`。
- “片段末概率”滑块的实际传送概率范围从 `25%–100%` 降为 `5%–20%`。
- 滑块参数 `teleportFrequency` 仍保存为 `0...1`，不迁移或重写用户现有设置。
- 片段末概率继续线性映射：`frequency = 0` 对应 `5%`，`frequency = 1` 对应 `20%`。

## 不变范围

- “随机隐现”和“鼠标附近提醒”的开关语义不变。
- 鼠标互动仍只在自主传送选中鼠标附近落点且两类互动素材均有效时触发。
- 热键、番茄钟、下载提醒等显式召唤仍不触发鼠标互动。
- 传送等待时间、隐藏时长、落点计算和动画效果不变。

## 测试

- 验证鼠标附近落点在随机值小于 `0.05` 时命中，在等于或大于 `0.05` 时回退角落。
- 验证片段末概率端点为 `0.05` 和 `0.20`。
- 验证片段末触发边界严格使用“小于概率”，并保留输入钳制行为。
- 运行完整 `swift test` 与 `swift build`。
