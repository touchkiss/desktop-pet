# 猫猫片段叠图标定

用户已确认详情面板方案。目标是以指定猫猫片段的抠像首帧为半透明标定物，手动统一其他片段的视觉体型。

## 交互与尺寸

- 默认选择猫猫列表第一项，可指定任意猫猫（包括互动猫），排除互动目标素材。参照 ID 使用 UserDefaults 保存；删除或改为目标素材后回退到第一只猫。
- 参照首帧及其倍率在选择时固定，切换待调整片段不会改变参照。点击“更新参照”可重新获取最新倍率；重启后从所存 ID 读取最新倍率。
- 标定画布默认显示当前片段首帧，拖动帧滑块可选取其他姿势。原有动态预览保留。
- 参照默认 30% 不透明度，可调整、隐藏。画布同时绘制底部基线和竖直中心线，可关闭。
- 两张图片按各自实际显示尺寸乘同一个视图倍率绘制，默认底部居中。调整片段倍率不重新适配画布。另设画布缩放，始终同时缩放两张图。
- 拖动只移动当前对照图，重置对齐可恢复底部居中；偏移不保存、不修改桌面猫的位置。
- 沿用 0.25–3.00 的片段倍率，增加数值输入，支持提交小数精调。滑块和输入都立即更新标定图、保存倍率并通知桌面窗口。
- 标定只使用普通显示倍率，不计入魔性阶段额外倍率。

## 实现边界

独立 ClipCalibrationView 负责 AppKit 控件与图片；ClipCalibrationGeometry 放 DesktopPetCore，负责共同比例、矩形、参照回退与输入合法性。DetailPanel 只负责接入与倍率联动。缺失图片时显示明确提示，不能用其他帧冒充首帧。沿用 macOS 13，无新增依赖，不重写帧文件。

## 验证

先测试共同比例保持真实尺寸比例、基线和偏移、异常尺寸、参照回退、输入有限值及钳制。运行 swift test、swift build、发布打包。检查 UI 的选择、切换、输入、透明度、拖动和帧选择。视觉体型依靠人工判断，不能保证不同姿态的外接框一致。
