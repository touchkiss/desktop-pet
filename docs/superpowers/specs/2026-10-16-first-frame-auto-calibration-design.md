# 首帧批量标定

用户确认片段基本由同一张首帧图片生成，采用首帧轮廓计算，无需头部识别。

- 基准为已选参照的首帧和倍率；排除互动目标素材，参照自身保持不变。
- 读取透明 PNG 首帧，缩小到不超过 512 像素，按 alpha 阈值取最大连通主体，排除零散抠像噪声。用主体面积换算未乘片段倍率的实际显示面积。
- 建议倍率 = 参照倍率 × sqrt(参照主体显示面积 / 当前主体显示面积)。不依赖当前倍率，因此重复计算不会累计缩放；全局倍率在比例中抵消。
- 比较主体宽高比例和归一化轮廓相似度；差异过大、缺帧、透明帧、无效尺寸和超出 0.25–3.00 的片段跳过并说明，不冒充成功。
- 在后台分析全部猫猫首帧，预览显示名称、原倍率、建议倍率、跳过原因；确认后一次保存。等待期间的手动变化须重新校验，不能覆盖新修改。
- 支持撤销最近一次批量应用；撤销前核对相关片段仍存在、角色和倍率未改动。保存失败恢复内存并提示。
- 不改变图像文件、帧序列和桌面位置。手动叠图标定仍可用。

验证核心轮廓、绝对倍率计算、反复应用、异常/低相似度和范围保护；使用真实素材只读分析检查结果，执行完整测试与发布打包。
